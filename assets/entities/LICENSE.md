# Entity figures

All from the Innerscene Free Parts Library (https://www.innerscene.com/tools/library/3d-parts),
each marked "Public domain (CC0)": CC0 1.0 Universal, "adapted from MakeHuman
CC0 assets" (MakeHuman/MPFB CC0 body, rig and skin). Library terms:
https://www.innerscene.com/tools/library/terms ("The dedication cannot be
withdrawn once the file is published"). Downloaded 2026-10-19.

- `sam.glb`: "Locomotion collection - Sam 3D Person, Animated",
  https://www.innerscene.com/tools/library/3d-parts/locomotion-collection-sam-3d-person-animated-dc23800f
  (a Copy)
- `jordan.glb`: "Locomotion collection - Jordan 3D Person, Animated",
  https://www.innerscene.com/tools/library/3d-parts/locomotion-collection-jordan-3d-person-animated-911f1584
  (a Copy)
- `harper.glb`: "Locomotion collection - Harper 3D Person, Animated",
  https://www.innerscene.com/tools/library/3d-parts/locomotion-collection-harper-3d-person-animated-797e1e2a
  (the Attendant: scaled to 1.27x, suit darkened in game)
- `crawler.glb`: "Human base mesh with editable 53-bone rig",
  https://www.innerscene.com/tools/library/3d-parts/human-base-mesh-with-editable-53-bone-rig-8e7c8ab1
  (the crawler: posed on all fours in code, `EntityBody.pose_crawl`)

Reduced for phones with `tools/blender/entities_slim.py`: decimated to about
9k triangles (16k for the base mesh), textures 512 px JPEG, normal maps,
teeth, eyelashes, scalp-root cards, ankle linings and the held briefcase
removed; only the Idle_Standing, Walk_Relaxed, Walk_Brisk and Run clips kept.
